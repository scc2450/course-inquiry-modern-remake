# Course Field Contract

The API returns normalized course rows with these stable keys:

- `classNo`: teaching class number
- `courseId`: source course identifier
- `courseName`: course title
- `courseType`: source course type label
- `credits`: numeric credits where available
- `remark`: source remark
- `scheduleTime`: time and classroom text
- `scheduleWeek`: week range text
- `teacher`: teacher text
- `url`: source detail URL
- `academicYear`: academic year such as `24-25`
- `term`: term code `1`, `2`, or `3`
- `scheduleType`: `BKSKB` or `YJSKB`
- `departmentId`: source department code
